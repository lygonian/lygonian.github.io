# Portfolio — Samet Kurt

Öffentliche statische Website mit Arbeitsproben aus Automation, Datenanalyse
und privaten technischen Projekten.

## Struktur
projekte werden sukzessiv hinzugefügt in die einzelnen reiter
- `index.html` — Start (technischer Einstiegspunkt für GitHub Pages)
- `automation.html` — operative Automationsfälle
- `datenanalyse.html` — Datenanalysen
- `private_projekte.html` — private Projekte
- `ueber_mich.html` — Profil, Arbeitsweise und wissenschaftlicher Hintergrund
  - `forschung/index.html` — ausführliche Forschungsfelder und Qualifikation
- `kontakt.html` — Kontakt über LinkedIn
- `assets/` — gemeinsames CSS, JavaScript und Bilder
